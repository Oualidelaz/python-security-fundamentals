# Python Practice Challenges

A structured collection of Python exercises designed to strengthen programming fundamentals through practical and cybersecurity-inspired problems.

The repository progresses from beginner concepts like variables and loops to more advanced topics such as hashing, XOR encryption, networking utilities, and random data generation.

---

# 🔥 Levels

## 🔹 Level 1 — Python Basics & Data Types

Topics:
- Variables
- Strings
- Numbers
- Booleans
- Input / Output

Includes exercises like:
- String reversing
- Number conversion
- Even/Odd checker
- Binary to decimal conversion

---

## 🔹 Level 2 — Control Flow & Loops

Topics:
- If / Else
- Loops
- Conditions
- Logical Operators

Includes exercises like:
- Password checker
- Login system
- FizzBuzz
- Prime numbers
- Palindrome detection

---

## 🔹 Level 3 — Lists, Tuples & Dictionaries

Topics:
- Lists
- Dictionaries
- Iteration
- Data manipulation

Includes exercises like:
- HTTP status dictionaries
- Port/service mapping
- Duplicate removal
- Manual sorting
- Frequency analysis

---

## 🔹 Level 4 — Functions & Modules

Topics:
- Functions
- Modules
- Return values
- Python libraries

Includes exercises like:
- Password strength checker
- MD5 hashing
- XOR encryption
- MAC address generation
- UUID generation
- Hostname resolution

---

## 🔥 Level 5 — Advanced Python Concepts

Topics:
- Lambda functions
- `map()`, `filter()`, `sorted()`
- First-class functions
- Closures and nested functions
- `nonlocal`
- `partial()`
- `reduce()`
- `lru_cache`
- Generators
- Performance optimization

Includes exercises like:
- Sorting and filtering cybersecurity user data
- Transforming data with `map()`
- Creating closures with counters
- Building a memory vault using nested functions
- Using `partial()` and `reduce()`
- Comparing Fibonacci with and without caching
- Generating Fibonacci numbers using `yield`
